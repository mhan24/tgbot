# 命令与权限

核对日期：2026-10-05。命令使用英文，说明使用中文；`[参数]` 为可选，实际输入不要带括号。

## 全员入口

| 命令 | 推荐位置 | 用途 |
|---|---|---|
| `/start` | 私聊 | 开始使用，获取入群/解封引导 |
| `/help` | 群、私聊 | 当前功能、权限和本群规则 |
| `/checkin` | 群 | 每日签到，头像对机器人不可见时提示并计警告 |
| `/points` | 私聊 | 选群查看积分、签到与发言额度和排名 |
| `/rank` | 私聊 | 选群查看积分排行榜，每页 50 人，按钮翻页 |
| `/milestones` | 私聊 | 原神榜：本群首次达标前 50 人，仅排名与昵称 |
| `/bin 45717360` | 群、私聊 | 查询 6–8 位 BIN |
| `/ai [问题]` | 群、私聊 | 输入问题，或回复文字/图片/相册；回复时可以不附问题 |
| `/report` | 群 | 回复目标消息交给 Jev 判断，经投票确认后处罚 |
| `/airdrop 最低积分 [活跃分钟] [人数] 奖品` | 群、私聊 | 创建或申请空投；普通成员需管理员同意 |
| `/airdrops [编号]` | 群、私聊 | 最近 20 条空投，或按编号查详情 |
| `/appeal [理由]` | 私聊 | 被拉黑者申请解封；不填理由则按提示发送 |
| `/cancel` | 私聊 | 取消正在填写的参数或解封理由 |

群内积分和榜单查询提供私聊跳转按钮，不在群里展示明细。多个群时私聊积分/榜单先选群；空投等操作使用当前管理群上下文。

普通中文文字别名：`签到`、`积分`、`排行榜`、`原神榜`。不带斜杠，不显示在 Telegram 命令菜单；不支持 `/中文命令`。

用户源消息保留，不因处理成功、失败或重复请求删除。普通成员和管理员没有每日群内操作总次数限制；签到每日一次、空投申请额度及 AI 冷却仍有效。

## 管理员

| 命令 | 推荐位置 | 用途 |
|---|---|---|
| `/manage [ID/@用户名]` | 群、私聊 | 打开成员管理面板；可回复成员消息指定目标，无参数查看黑白名单 |
| `/audit [ID/@用户名]` | 群 | 无参数最近 100 条全部日志；指定用户查涉及该用户的最近 20 条 |
| `/status` | 群 | 本群运行状态 |
| `/groups` | 私聊 | 查看、启停管理群，选择当前私聊管理群；实际操作按按钮权限核验 |

匿名管理员需切换个人身份。显式填写的 ID/@用户名优先于回复目标；用户名必须已收录且能重新核验，否则使用数字 ID 或回复用户消息。

### `/manage` 面板

回复目标成员消息发送 `/manage`，或发送 `/manage @username`、`/manage 123456789`。私聊先通过 `/groups` 选择当前群。

| 按钮 | 行为 |
|---|---|
| 警告一次 | 累计一次；达到 3 次拉黑并请求删除全部群消息 |
| 清零警告 | 不解除现有临时禁言或黑名单 |
| 禁言 1 小时 / 按群设置禁言 | 独立禁言，不增加警告 |
| 解除禁言 | 仍未完成验证时拒绝解除 |
| 拉黑并删消息 | 二次确认；移出、阻止重入、移除白名单，并请求删除全部群消息 |
| 解封并清零警告 | Telegram 成功解封后清理本地状态；用户需重新入群，不恢复白名单 |
| 加入 / 移出白名单 | 设置或取消本群信任豁免 |
| 关闭面板 | 立即失效并删除，不创建新面板 |

仅打开面板的当前管理员可点击。面板 5 分钟有效，过期后 30 秒清理；操作后的旧面板失效并在 30 秒清理，显示新面板。无目标时列出各最近 20 名黑白名单成员供选择。

## 群主

| 命令 | 位置 | 用途 |
|---|---|---|
| `/group_add [@频道或频道ID]` | 新群 | 登记该群；先授予机器人管理员权限 |
| `/settings` | 私聊 | 按钮选群和配置项，直接发送新值，`/cancel` 取消 |
| `/appeals` | 私聊 | 查看最早 20 条待审解封申请，按钮批准或拒绝 |

每群独立配置，修改时重新检查当前群主身份。群主先私聊 `/start`，才能收到解封申请通知。申请显示昵称提及、用户名及 ID；多个群被拉黑时可用 `/appeal 群ID 理由` 指定。

## 常见示例

```text
/airdrop 50 神秘奖品
/airdrop 50 840 5 奖品
/airdrop 50 0 5 奖品
/airdrops 23
/ai 总结这条消息
/manage @username
/audit 123456789
/appeal -1000000000001 我已了解群规则，申请解封
```

空投默认 1 人、最多 20 人；不限制活跃度但指定人数时活跃分钟填 `0`。普通成员每天一次申请，管理员每日直接创建一次，额外申请需群主批准。

Jev 必须回复目标消息发送 `/report`；1 名管理员或 5 名当前群员同意才警告，管理员可驳回。AI 空命令需回复消息，成功回答标注模型 ID。
