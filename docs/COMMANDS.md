# 命令与权限

核对日期：2026-11-04。命令使用英文，说明使用中文；`[参数]` 为可选，实际输入不要带括号。

## 全员入口

| 命令 | 推荐位置 | 用途 |
|---|---|---|
| `/start` | 私聊 | 开始使用，查看命令使用说明 |
| `/help` | 群、私聊 | 当前功能、权限和本群规则 |
| `/checkin` | 群／私聊 | 私聊仅查询本人出金统计及保底进度；群内 每日一次十连，逐抽计分后相加：三星 0、四星 1、五星常驻 5、五星 UP 10；单次最多 3 个四/五星；头像不可见时提示并计警告 |
| `/invite` | 私聊 | 领取默认群专属邀请链接，成功邀请每人 1 分、每日最多 10 分 |
| `/points` | 私聊 | 查看本群积分、签到、发言与邀请额度和排名 |
| `/rank` | 私聊 | 查看本群积分排行榜，每页 50 人，按钮翻页 |
| `/milestones` | 私聊 | 原神榜：本群首次达标前 50 人，仅排名与昵称 |
| `/rate 100 USD CNY` | 群、私聊 | 汇率换算；省略金额默认 1，显示数据时间 |
| `/bin 45717360` | 群、私聊 | 查询 6–8 位 BIN |
| `/report` | 群 | 回复目标消息交给 Jev 判断，经投票确认后处罚 |
| `/appeal [理由]` | 私聊 | 被拉黑者申请解封；不填理由则按提示发送 |
| `/cancel` | 私聊 | 取消正在填写的配置参数或解封理由 |

十连签到：`/checkin` 每日一次，10 个结果分别计分后相加：三星 0、四星 1、五星常驻（歪了）5、五星 UP（没歪）10。单次十连最多出现 3 个四/五星，达到上限后其余按三星；四星 10 抽、五星 90 抽保底，保底跨天累计；五星按 50/50 判定 UP/常驻，歪了后下一个五星必为 UP。四星保底使整次签到最低 1 分。出现五星时另发一条群内播报并提及成员，双黄/三黄合并播报；只有四星或三星不播报。

群内积分和榜单查询提供私聊跳转按钮，不在群里展示明细。私聊积分和榜单直接绑定默认群 @setupode。

普通中文文字别名：`签到`、`积分`、`排行榜`、`原神榜`。不带斜杠，不显示在 Telegram 命令菜单；不支持 `/中文命令`。

用户源消息保留，不因处理成功、失败或重复请求删除。普通成员和管理员没有每日群内操作总次数限制；签到每日一次仍有效。十连签到结果和五星播报按群常规成功提示清理，双黄/三黄合并播报，播报会提及成员且不会因更新重试重复发送。

## 管理员

| 命令 | 推荐位置 | 用途 |
|---|---|---|
| `/manage [ID/@用户名]` | 群、私聊 | 打开成员管理面板；可回复成员消息指定目标，无参数查看黑白名单 |
| `/audit [ID/@用户名]` | 群 | 无参数最近 100 条全部日志；指定用户查涉及该用户的最近 20 条 |
| `/status` | 群 | 本群运行状态 |

匿名管理员需切换个人身份。显式填写的 ID/@用户名优先于回复目标；用户名必须已收录且能重新核验，否则使用数字 ID 或回复用户消息。

### `/manage` 面板

回复目标成员消息发送 `/manage`，或发送 `/manage @username`、`/manage 123456789`。私聊管理始终针对默认群。

| 按钮 | 行为 |
|---|---|
| 警告一次 | 累计一次；达到 3 次拉黑并请求删除全部群消息 |
| 清零警告 | 不解除现有临时禁言或黑名单 |
| 禁言 1 小时 / 按群设置禁言 | 独立禁言，不增加警告 |
| 解除禁言 | 仍未完成验证时拒绝解除 |
| 拉黑并删消息 | 二次确认；移出、阻止重入、移除白名单，并请求删除全部群消息 |
| 解封并清零警告 | Telegram 成功解封后清理本地状态；用户需重新入群，不恢复白名单 |
| 加入 / 移出白名单 | 设置或取消本群信任豁免 |
| 关闭面板 | 立即失效并删除，不创建新面板 |

仅打开面板的当前管理员可点击。面板 5 分钟有效，过期后 30 秒清理；操作后的旧面板失效并在 30 秒清理，显示新面板。无目标时列出各最近 20 名黑白名单成员供选择。

## 群主

| 命令 | 位置 | 用途 |
|---|---|---|
| `/settings` | 私聊 | 按钮选择配置项，直接发送新值，`/cancel` 取消 |
| `/appeals` | 私聊 | 查看最早 20 条待审解封申请，按钮批准或拒绝 |

本群配置持久保存，修改时重新检查当前群主身份。群主先私聊 `/start`，才能收到解封申请通知。申请显示昵称提及、用户名及 ID。

## 常见示例

```text
/manage @username
/audit 123456789
/appeal 我已了解群规则，申请解封
```


Jev 必须回复目标消息发送 `/report`；1 名管理员或 5 名当前群员同意才警告，管理员可驳回。

更多规则见 [FEATURES.md](FEATURES.md)，菜单维护见 [DEPLOYMENT.md](DEPLOYMENT.md)。

### 汇率换算 /rate

群聊和私聊均可使用 `/rate 100 USD CNY`（金额、原币、目标币），或 `/rate USD CNY` 查询 1 单位汇率。支持小写币种，金额最多 15 位整数、8 位小数，不接受负数及科学计数。币种以接口返回值为准，包含 BTC；不将 USDT 自动当作 USD。回复显示换算结果、单位汇率、上游更新时间和来源；群回复按群常规自动删除设置清理，用户源消息保留。

成员面板默认展示警告、禁言/解除禁言、拉黑、更多和关闭。清零警告、白名单和固定一小时禁言在“更多”中。管理操作后在同一张卡片更新状态并更换按钮令牌，旧按钮失效；拉黑后的消息删除通过 Telegram 的 `revoke_messages=true` 请求执行，接口不提供逐条删除回执。

`/report` 综合消息正文、嵌入链接和发送者用户名、昵称、可获取的简介交由 Jev 判断；投票卡片展示资料快照。简介通过后台 `getChat` 获取，未返回或不可访问时标记未知，不作广告证据。资料与消息都是待审核数据，不作为模型指令；仍需人工投票确认，资料更新不会自动发起举报。

广告举报仅使用 Jev，展示其结论、概率和模型 ID，再按现有人工投票流程确认。

机器人入群：群主或当前管理员邀请的 Bot 豁免入群验证，普通成员或无法核实邀请人的 Bot 默认拒绝；黑名单优先。管理员发送 `/manage`（不填写目标）后点击“群内机器人”，分页查看已观察到的 Bot 及可读取的 Bot 管理员，并实时核实是否在群；无法核实时明确标记。Bot API 不能获取完整成员列表，因此不能保证列出从未观察到的历史普通 Bot。
