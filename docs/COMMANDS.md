# 机器人命令说明

核对日期：2026-10-01。以当前处理代码为准；菜单命令使用英文，说明使用中文。

`[参数]` 表示可选，尖括号表示必填；实际输入时不要带括号。群组配置可改变积分范围、冷却和时长，下文不写死这些值。

## 普通成员

| 命令 | 位置 | 用途与参数 |
|---|---|---|
| `/start` | 私聊 | 打开机器人，获取入群或解封申请引导 |
| `/help` | 群、私聊 | 查看功能、权限和当前群配置说明 |
| `/checkin` | 群 | 每日签到；头像对机器人不可见会提示并计警告，不加分 |
| `/points` | 私聊 | 查看积分、今日积分和排名；多群时选择群组 |
| `/rank` | 私聊 | 积分排行榜，每页 50 人，按钮翻页，不提及成员 |
| `/milestones` | 私聊 | 原神榜：首次达到本群积分门槛的前 50 位，与当前头衔无关 |
| `/bin <6–8 位数字>` | 群、私聊 | 查询 BIN，例如 `/bin 45717360` |
| `/ai <问题>` | 群、私聊 | AI 问答；也可回复消息发送 `/ai`，可附加问题；回答标注模型 ID |
| `/report` | 群 | 必须回复目标文字消息或带文字说明的媒体，交给 Jev 判断广告 |
| `/airdrop <最低积分> [活跃分钟] [中奖人数] <奖品>` | 群、私聊 | 发起本群空投，例如 `/airdrop 50 840 5 奖品`；普通成员每天可申请一次，需管理员批准 |
| `/airdrops [编号]` | 群、私聊 | 不带编号查看最近 20 条空投；带编号查看详情 |
| `/appeal [理由]` | 私聊 | 被拉黑者申请解封；不写理由则按提示发送；每天最多一次，待审不可重复提交 |
| `/cancel` | 私聊 | 取消当前参数修改或解封理由填写；没有待填写内容时不执行取消 |

- 群内发送 `/points`、`/rank`、`/milestones` 会提示转私聊；签到、积分和榜单的源消息处理后删除。
- 保留普通中文文本别名：`签到`、`积分`、`排行榜`、`原神榜`。不支持带斜杠的中文命令。
- 普通成员 AI 调用受本群冷却限制；管理员、白名单豁免。群内普通命令另有每日次数限制。
- Jev 只由 `/report` 手动触发。判为可疑后，1 名管理员或 5 名不同群员同意才警告一次；管理员可驳回。
- 空投管理员每天可直接发起一次，额外申请需群主批准；群主不限。私聊空投使用当前管理群上下文。
- 用户在多个群被拉黑时可用 `/appeal <群ID> <理由>` 指定群组。

## 管理员（群内执行）

目标通常用回复消息指定，也可以填写数字 ID 或机器人已收录的 `@用户名`。匿名管理员须切换个人身份。

| 命令 | 说明 |
|---|---|
| `/warn [目标] [原因]` | 警告一次；累计 3 次禁言、移出并拉黑 |
| `/warnings [目标]` | 查看该用户的警告 |
| `/resetwarn [目标]` | 清零警告，不自动解封 |
| `/mute [目标] [分钟]` | 禁言，不填分钟使用本群默认时长 |
| `/unmute [目标]` | 解除禁言 |
| `/ban [目标] [原因]` | 拉黑并移出，要求 Telegram 删除该用户的群消息 |
| `/unban [目标]` | 解除封禁，用户仍需重新入群 |
| `/white [目标] [备注]` | 加入本群白名单 |
| `/unwhite [目标]` | 移出白名单 |
| `/whitelist` | 查看白名单 |
| `/audit [目标]` | 无参数：最近 100 条全部操作；带数字 ID 或 @用户名：涉及该用户的最近 20 条 |
| `/status` | 查看本群运行和验证、黑名单、标签状态 |

示例：回复目标消息发送 `/warn 广告`；或者单独发送 `/mute @username 30`。回复消息时，额外数字参数按该命令的参数处理（例如禁言分钟）；避免同时回复一人又填写另一人的数字 ID。

## 多群管理与群主

| 命令 | 权限与位置 | 说明 |
|---|---|---|
| `/group_add [@频道或频道ID]` | 群主，在新群内 | 登记新管理群；先将机器人设为管理员 |
| `/groups` | 已管理群管理员，私聊 | 查看管理群，通过按钮启停、选择当前私聊管理群；按钮再次检查权限 |
| `/settings` | 对应群群主，私聊 | 选择群组与配置项；直接发新值，或 `/cancel` 取消；输入有效期 10 分钟 |
| `/appeals` | 当前群群主，私聊 | 查看最多 20 条待处理解封申请，点击批准或拒绝 |

解封申请显示数字 ID、用户名及可点击提及的昵称。群主先私聊 `/start`，机器人才能发送通知。积分榜单自行选群；其他群级私聊操作使用对应群上下文，数据相互隔离。

AI 模型 ID 不提供设置入口。配置值以本群 `/settings` 和 `/help` 为准。

## 维护说明

- `bot.py`：帮助、积分入口、群管、配置与多群分发。
- `ai_chat.py`、`airdrop.py`、`appeals.py`、`jev_ads.py`：各自功能的命令和按钮处理。
- `scripts/update_commands.py`：同步已有 Telegram 菜单的命令说明、移除不存在的命令；不会新增聊天通知。
- 修改命令时同步本页、`/help` 和菜单说明；中文普通文本别名与斜杠命令分开维护。

AI 引用会优先沿已保存的消息回复关系还原对话链，再参考近期群聊。AI 回答记录关联原问题，群聊背景标注消息 ID 与回复目标；论坛话题按话题隔离。旧记录缺少回复关系、记录已过期或未收录时会明确标注缺失，不推测历史。

AI 图片分析：回复照片或 JPG/PNG/WebP 图片文件发送 `/ai`（可附问题），也支持图片说明中的 `/ai 问题`。同一相册的已记录图片会按顺序一起发送，最多 10 张、单张 10 MB、合计 20 MB；相册索引保留 24 小时，不保存图片内容。旧相册未收录的图片无法补回，可重新发送；引用中仍附带的单张图片可直接读取。图片下载失败会提示，不会退回只解释标题。
