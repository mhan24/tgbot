# Telegram 群管理机器人

使用 Python 3.9+ 标准库与 SQLite，实现入群验证、成员管理、积分和广告举报。默认群为 [@setupode](https://t.me/setupode)，仅处理这个群的业务。

## 功能

| 功能 | 使用方式与规则 |
|---|---|
| 入群验证 | 检查关联频道关注状态、Bot 身份与黑名单，普通成员完成算术验证 |
| 成员管理 | `/manage` 按钮处理警告、禁言、拉黑、解封和白名单；累计 3 次警告拉黑并请求 Telegram 删除该成员全部群消息 |
| 广告举报 | 回复消息发送 `/report`，Jev 判断后由 1 名管理员或 5 名群员确认；确认后删除广告并警告一次 |
| 积分 | `/checkin` 每日十连，逐抽计分后相加：三星 0、四星 1、五星常驻 5、五星 UP 10；单次最多 3 个四/五星；发言默认每条 1 分、每日最多 5 分 |
| 邀请积分 | 私聊 `/invite` 领取专属链接；成功邀请真人进群每人得 1 分，每天最多 10 分 |
| 榜单 | 私聊 `/points`、`/rank`、`/milestones`，查看本群数据；积分榜每页 50 人，原神榜展示首次达标前 50 名 |
| 汇率换算 | `/rate 100 USD CNY`，或 `/rate USD CNY`；小时缓存，显示数据更新时间 |
| BIN 查询 | `/bin 45717360`，查询 6–8 位前缀 |
| 群主配置 | 私聊 `/settings`，直接修改默认群参数 |
| 解封与审计 | 私聊 `/appeal` 提交理由，由群主处理；`/audit` 无参数查看最近 100 条操作日志 |

Telegram 菜单使用英文命令、中文说明。普通文字 `签到`、`积分`、`排行榜`、`原神榜` 也可触发对应功能，不支持中文斜杠命令。完整入口见 [命令与权限](docs/COMMANDS.md)。

## 消息与权限规则

- 用户源消息保留；普通成功提示默认 30 秒，失败及处罚通知 2 分钟。私聊只清理完成的机器人旧步骤，最终预览和结果保留。
- 验证、投票、审批和管理面板保留到流程结束，再按规则清理；关闭管理面板立即删除。
- 群内操作没有每日总次数上限，签到每日一次。
- 广告仅通过 `/report` 手动提交，没有自动扫描；Jev 只处理举报提交，不自动扫描群消息。
- 同一成员仅计一次邀请积分，普通共享链接不计。私聊 `/points` 查看今日邀请积分。
- 十连签到结果默认 30 秒清理；出现五星时另发一条群内播报并提及成员，双黄/三黄会合并播报，同样按群常规时长清理。用户签到源消息保留。
- 普通成员头像不可见时，发言不计分；签到则提示并计一次警告。完整三天仅签到、没有正常发言会被禁言（本群默认禁言时长，`/settings` 可调），积分不清零，管理员与白名单豁免。
- 管理按钮重新核验所属群、操作者和当前权限。群主配置、积分、名单和历史仅属于默认群。

## 快速启动

无需安装第三方 Python 包。

```sh
cp .env.example .env
chmod 600 .env
# 编辑 .env，填写 TELEGRAM_BOT_TOKEN、GROUP_ID、CHANNEL_ID
python3 -m unittest discover -s tests -q
python3 bot.py
```

运行前将机器人设为群和关联频道的管理员，授予删除消息、限制成员、邀请成员等权限；成员标签需要 Telegram 对应管理权限。不要同时运行多个轮询同一 token 的实例。生产部署参考 [部署文档](docs/DEPLOYMENT.md) 和 [systemd 服务](tgbot.service)。

### 可选服务

| 配置 | 用途 |
|---|---|
| `JEV_API_KEY`、`JEV_MODEL` | `/report` 广告举报判断；未配置时举报入口不可用 |
| ExchangeRate.fun、Binlist | 汇率与 BIN 公共查询接口，无需额外密钥 |

机器人只使用已收到或已记录的信息，不能恢复未保存的历史群聊，也不能通过 Bot API 枚举所有历史成员或读取最后在线时间。

## 每日十连签到

群内发送 `/checkin` 或普通文字 `签到`，每天一次。一次签到等于一次十连，10 个结果分别计分后相加：

- 三星：0 分
- 四星：1 分
- 五星常驻（歪了）：5 分
- 五星 UP（没歪）：10 分

单次十连最多出现 3 个四/五星，达到上限后其余结果按三星计算。四星 10 抽保底，五星 90 抽保底，保底次数按用户跨天累计；四星保底使整次签到最低 1 分。五星基础概率 0.6%，从第 74 抽开始提升，第 90 抽必出；四星基础概率 5.1%。

例如：2 个四星得 2 分；1 个五星 UP + 2 个四星得 12 分；1 个五星常驻 + 1 个四星得 6 分。

五星按 50/50 判定 UP 或常驻；歪了常驻后，下一个五星必为 UP（大保底）。小保底和大保底都是五星，小保底可能歪出常驻 5 分，也可能直接 UP 10 分；大保底必为 UP 10 分。

签到结果在群内回复，显示 10 个结果、各类数量、总分、四星/五星保底进度和下次是否大保底。出现五星时另发一条群内播报并提及成员，双黄/三黄合并播报；只有四星或三星时不播报。签到仍要求头像对机器人可见，头像不可见时按原规则提示并计警告。结果和播报默认 30 秒清理，用户源消息保留。
