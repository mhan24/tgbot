# Telegram 多群管理机器人

Python 3.9+、标准库与 SQLite 实现的 Telegram 群管机器人。各群独立保存积分、名单、举报、活动和 AI 上下文。

## 当前功能

- 入群：关联频道关注检查、算术验证、黑名单拦截。
- 广告：回复消息发送 `/report`，由 Jev 判断；1 名管理员或 5 名群员同意后删除广告并警告。
- 管理：`/manage` 按钮面板处理警告、禁言、拉黑、解封和白名单；累计 3 次警告拉黑并请求删除全部群消息。
- 积分：每日签到、发言积分、私聊分页排行榜、首次达标前 50 名及达标祝贺。
- 空投：积分和活跃门槛、多名中奖者、成员申请审批、Base 区块证明、历史查询。
- AI：`/ai` 支持文字、回复链、图片与已记录相册，回答标注模型 ID。
- 多群：登记与启停、私聊选群、群主按钮配置、解封申请和审计日志。
- BIN：`/bin` 查询 6–8 位前缀。

## 交互规则

用户命令源消息全部保留，普通成员和管理员均无每日群内操作次数上限。签到每日一次、空投额度和 AI 冷却仍独立生效。

普通群内机器人消息默认 **30 秒后删除**，包括 AI 回答、空投结果、达标祝贺与管理反馈。验证、审批、投票和管理面板保留到流程结束后再计时；关闭管理面板立即删除。私聊不参与群内自动清理。广告确认和拉黑产生的违规消息清理属于处罚规则。

## 本地运行

```sh
cp .env.example .env
chmod 600 .env
# 填写 TELEGRAM_BOT_TOKEN、GROUP_ID、CHANNEL_ID 和需要启用的 API 凭据
python3 -m unittest discover -s tests -v
python3 bot.py
```

运行前，将机器人设为群和关联频道的管理员。生产部署使用 [tgbot.service](tgbot.service)。不要同时运行多个轮询同一 token 的实例。

`.env`、密钥、SQLite 数据、Telegram 会话及运行日志不提交到仓库；`.env.example` 仅提供配置模板。
